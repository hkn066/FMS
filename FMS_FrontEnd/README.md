# FMS Frontend

Law Office Client and Case Management Platform — Next.js web application.

## Stack

- Next.js
- TypeScript
- React Query
- Tailwind CSS
- Radix UI

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

App runs on `http://localhost:3000` by default.

## Development

```bash
npm run lint
npm run build
```

## Repository

Part of the **FMS** (Firm Management System) project.
