# 02_MEMORY

Projenin güncel durumu ve oturumlar arası hafıza.

**Birincil kaynak:** Bu dizin.

## Dosyalar

| Dosya | İçerik |
|-------|--------|
| `CURRENT_STATE.md` | Modül durumu, route tablosu, bilinen sorunlar |
| `LAST_SESSION.md` | Son oturum özeti |
| `CHANGELOG.md` | Önemli değişiklik günlüğü |

## Güncelleme Protokolü

Her kodlama görevi sonrası agent şunları günceller:

1. `CURRENT_STATE.md`
2. `LAST_SESSION.md`
3. `CHANGELOG.md`

Tamamlanan görevler → `03_PLANNING/DONE.md`
